\# DoseCheck



DoseCheck is a caregiver check-in for one parent's daily pills. The web page acts like an Alexa+ conversation. That page is an MCP client. It talks to a local MCP server over Streamable HTTP, protocol 2025-11-25.



This is a hackathon demo for the Alexa+ track. It is not a medical device.



\## What you can do



\- See which of Mom's pills are due now.

\- Mark the morning blood pressure pill as taken.

\- Hear today's summary.



The evening statin is not due yet. Two morning pills start out due.



\## Requirements



\- Python 3.11 or newer

\- No API keys
